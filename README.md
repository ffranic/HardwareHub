# Hardware Hub

Hardware Hub is a full-stack web application for managing and
purchasing IT equipment, developed as a university project at
the Zagreb University of Applied Sciences (TVZ).

## Technologies

- Java
- Spring Boot
- Spring Security
- Spring Data JPA / Hibernate
- MySQL
- HTML, CSS, JavaScript
- Gradle

## Main Features

- User authentication and session management
- ADMIN and CUSTOMER authorization
- Product and category management
- Shopping cart and checkout
- Order management
- PDF generation
- Croatian / English localization
- Product image storage using BLOBs

## Security Features

- BCrypt password hashing
- SHA-256 pre-hashing with pepper
- Role-based authorization
- AES-256-GCM encrypted activity logs
- RSA digital signatures
- Secure log archives
- Order signature verification
- Concurrent stock management

## Additional Features

- External REST API integration for EUR/USD exchange rates
- Multithreaded PDF generation
- Binary order archive
- Application activity logging
