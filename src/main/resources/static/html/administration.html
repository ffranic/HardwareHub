    System maintenance & security

    Tools for maintaining inventory files, securing activity logs, checking file integrity and running system analysis.

    Audit activity

    Review recent and archived security-relevant activity. Logs are encrypted and archived automatically in the background.

    Recent activity Shows current encrypted activity logs after temporary in-memory decryption.
    Archived activity Shows older activity logs grouped by archive date.
    Audit integrity Verifies SHA-256 hashes of current and archived encrypted log files.

    Inventory XML snapshot

    Review the latest product stock snapshot stored in XML format.

    Inventory snapshot Refreshes the XML snapshot from the current database state and displays it in a structured view.
    Snapshot integrity Verifies whether the generated XML snapshot file was modified after creation.

    Order binary archive

    Completed and cancelled orders are automatically stored in daily binary archive files.
